# Burger Clicker
Est ce que vous aimez l'espace et les burgers ? Alors Burger Clicker est fait pour vous, le but du jeu est de cliquer sur le burger qui vagabonde dans l'espace et d'avoir le plus de burger possible ! (comme cookie clicker lol)

Le jeu à été fait avec le framework LÖVE2D en lua, le jeu est actuellement disponible uniquement sur Android.

Abonnez vous à mon tiktok pour suivre l'avancé du jeu : @math.d52100

Do you like space and burgers? Then Burger Clicker is made for you, the goal of the game is to click on the burger which wanders in space and to have as many burgers as possible! (like cookie clicker lol)

The game was made with the LÖVE2D framework in lua, the game is currently only available on Android.
